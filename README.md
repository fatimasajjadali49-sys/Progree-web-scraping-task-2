
# Automated Web Scraping & Data Extraction Pipeline

## Internship
Progree — Data Science Internship  
Task 02

## Project Overview
This project extracts book information from a public website, cleans and processes the collected data, performs price analysis, and saves the results in a CSV file.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

## Dataset Details
- Total books collected: 1,000
- Columns: Title, Price, Availability
- Missing values after cleaning: 0
- Duplicate rows after cleaning: 0

## Key Features
- Automated multi-page web scraping
- Data cleaning and preprocessing
- CSV data export
- Price analysis
- Price distribution visualization

## Output Files
- `web_scraping.py`
- `scraped_books.csv`
- `book_price_distribution.png`

## Price Analysis
- Average price: £35.07
- Highest price: £59.99
- Lowest price: £10.00
